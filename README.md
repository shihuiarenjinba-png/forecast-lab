# 将来予測スクリプト置き場

将来予測（forecast）系のアプリ・スクリプトをここに置きます。

## ここに置くもの

- 時系列予測（ARIMA、Prophet、状態空間モデルなど）
- レジーム遷移確率の将来推定
- ファクターリターンの将来予測
- キャッシュフロー・損益の将来シミュレーション

## ここに置かないもの

- 過去データの統計的分析 → `10-research-lab/`
- 財務比率・DCF などの現状評価 → `40-finance/` 直下の既存アプリ
- データ取得そのもの → `20-factor-data/`

## ランチャー登録方法

新しいアプリを追加したら、`app-registry/<id>.json` を作って登録します。
ランチャー本体（`launcher.py`）の編集は不要です。

カテゴリ名は `Forecast` を推奨します。
